# Kizuna 1対1チャットサンプル

`@aituber-onair/kizuna` を1対1チャットへ組み込む方法を確認できるブラウザ
サンプルです。メッセージを入力すると、キャラクターが感情付きの定型文で返答し、
1往復を `message` と感情付き `reaction` の接触として記録します。

関係性パネルには、ポイント、温かさ、関係ステージ、正規化した親密度を表示します。
親密度バーは変更前から変更後まで滑らかに伸び、SVGグラフには会話ごとの推移が
残ります。LLM、TTS、APIキー、ネットワークサービス、実行時依存は不要です。

このデモの感情判定には、小さな採点式辞書を代用品として使います。表記揺れを
正規化し、一致した言葉を定型応答の感情へ対応させます。実際のアプリでは、
`react-pngtuber-app` の組み込み例と同様に、通常は LLM が返したキャラクターの
反応感情を valence の信号に使います。moderation API やアプリ独自規則の結果で、
Kizuna を呼ぶ前に `valence` / `severity` を上書きすることもできます。

「今日も会えてうれしい」→「ヤダ」→穏やかな言葉を数回、の順で試してください。
否定的な入力には `angry` の定型応答を返すため、メッセージと reaction によって
バーとグラフが目に見えて下がり、その後の穏やかな会話で温かさとスコアが
修復します。重大な語では `severity: 'grave'` も設定します。不在を罰せず、
応答も罪悪感を誘わずに境界を伝えます。

リポジトリルートから:

```sh
npm -w @aituber-onair/kizuna run example:chat-bond-sample
```

このディレクトリから:

```sh
npm run dev
```
