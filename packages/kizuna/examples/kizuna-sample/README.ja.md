# AITuber OnAir Kizuna サンプル

`@aituber-onair/kizuna` が、AI キャラクターとのさまざまな接触を絆へ変える様子を試せるブラウザラボです。人物・接触種別・感情を選ぶと、ポイント、ステージ、温かさ、継続、実績、LLM コンテキストがリアルタイムに更新されます。

シミュレーション時計を進めることで、実際に待たずに絆の温かさの減衰や継続の途切れを確認できます。

```sh
npm -w @aituber-onair/kizuna run example:kizuna-sample
```

サンプルのディレクトリから直接起動することもできます。

```sh
cd packages/kizuna/examples/kizuna-sample
npm run dev
```
