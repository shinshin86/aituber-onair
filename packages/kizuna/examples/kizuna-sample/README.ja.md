# Kizuna 視聴者との親密度シミュレーター

AIキャラクターが視聴者との接触を記録したとき、何が変わるかを確認できる
ブラウザサンプルです。視聴者・接触の種類・感情を選ぶと、その視聴者のポイント、
温かさ、関係ステージ、継続、実績、LLMへ渡せる関係性の文脈が更新されます。

絆スコアは育つだけでなく、不和で下がることもあります。温かさは不和や仲直りへ
すぐ反応し、シミュレーション時刻を進めると下限へ近づきます。軽い否定的接触で
「不和→冷却→修復」を試したり、重大な傷を作って複数日の親切な接触で癒したり
できます。右上の通知と視聴者ごとの親密度バーは、上昇・低下の両方を動きで
示します。

会わない時間は絆スコアやステージを下げず、温かさだけを冷まします。温かさが
低い間は贈り物の効果も小さくなり、不和直後の信頼を買い戻せません。

LLMやAPIキーは不要です。シミュレーション時刻を進めることで、実際に待たずに
温かさの減衰や継続の途切れを確認できます。

```sh
npm -w @aituber-onair/kizuna run example:kizuna-sample
```

サンプルのディレクトリから直接起動することもできます。

```sh
cd packages/kizuna/examples/kizuna-sample
npm run dev
```
