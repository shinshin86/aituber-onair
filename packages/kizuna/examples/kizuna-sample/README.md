# AITuber OnAir Kizuna Sample

This browser lab shows how `@aituber-onair/kizuna` turns generic contacts into
a bond with an AI character. Choose a person, contact kind, and emotion to see
points, stages, warmth, continuity, achievements, and LLM context update live.

The simulated clock makes warmth decay and continuity gaps visible without
waiting in real time.

```sh
npm -w @aituber-onair/kizuna run example:kizuna-sample
```

You can also run it from the sample directory:

```sh
cd packages/kizuna/examples/kizuna-sample
npm run dev
```
